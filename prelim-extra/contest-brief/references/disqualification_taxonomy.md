# 실격·유의 조건 6분류표

공고의 위험 문장(risk_lines)을 아래 6분류로 나누어 표에 옮긴다. 한 문장이 여러 분류에 걸리면 모두 표기한다.

| 분류 | 정의 | 대표 키워드 |
|---|---|---|
| 1. 실격/심사 제외 | 심사 대상에서 제외되거나 접수가 무효가 되는 조건 | 실격, 제외, 불가, 무효, 취소, 반려, 미준수, 위반, 부정, 허위 |
| 2. 감점 | 심사에서 감점되는 조건 | 감점, 불이익, 감점 처리 |
| 3. 무효/환수/박탈 | 이미 인정된 것을 무효화·환수·자격 박탈하는 조건 | 환수, 박탈, 환수조치, 자격 박탈 |
| 4. 금지/제한 | 제출물·재사용·인력 등에 대한 금지·제한 | 금지, 도용, 표절, 중복, 재사용 금지, 팀 구성 위반 |
| 5. 유의/주의/엄수 | 준수해야 할 유의 사항(위반 시 불이익 가능) | 유의, 주의, 엄수, 반드시, 준수사항 |
| 6. 기타/문의 | 위 분류엔 해당하지 않으나 지켜야 할 조건·문의 안내 | 문의, 확인,參考(참고), 기타사항 |

근거: 각 행에 원문 요지 + 근거 줄번호([L줄번호])를 함께 적는다.
