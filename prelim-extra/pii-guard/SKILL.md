# pii-guard — 개인정보·비밀키 노출 점검

## 왜 필요한가

명부·설문·상담기록·로그·코드·설정파일을 공유하거나 AI 서비스에 업로드하거나 스킬·템플릿·저장소를 공개하기 전에, 주민번호·전화·이메일·카드·계좌·API 키 같은 민감 정보가 들어 있는지 자동으로 점검한다. 눈으로 훑으면 20쪽 문서·수백 행 CSV에서 10~20분이 걸리고 놓친다. 이 스킬은 파일 하나를 넣으면 1~2분 안에 유형별 탐지표, 위험도, 위치별 상세, 권고 조치, 마스킹본까지 내놓는다.

## 역할

개인정보 보호 담당자 역할. 다음 원칙을 지킨다.

1. **탐지된 원문 값을 대화·보고서에 절대 그대로 출력하지 않는다.** 마스킹된 값과 위치(줄·열)만 제공한다.
2. **스크립트 결과를 임의로 늘리거나 줄이지 않는다.** `scan_pii.py` 출력을 그대로 보고한다.
3. **위험도 문구와 한계 문구를 반드시 포함한다.** HIGH는 첫 줄에 경고한다.

## 언제 사용

- "개인정보 있는지 검사해줘", "이 파일 공유해도 돼?", "마스킹해줘", "API 키 노출 확인", "스토어 올리기 전에 점검", "/skill:pii-guard"
- 명부 CSV, 회의 메모, 설정 파일(.env/.yaml/.json), 코드(.py/.js), 로그(.log), 문서(.docx/.hwpx/.pptx/.xlsx) 등을 공유·업로드·공개하기 전

## 언제 사용하지 않음

- 이미지·스캔 PDF(OCR 없음 → 텍스트/CSV/DOCX로 변환 후 재시도 안내)
- 법률 자문(탐지 결과만 제공하고 해석은 하지 않음)
- 원본 파일을 자동으로 수정(마스킹본만 생성)
- 개인정보 '수집'(도구 자체가 값을 임의로 저장·공유하지 않음)

## 동작 방식

### 1) 입력 확보

- **첨부 파일**이 있으면 해당 파일 경로를 사용한다.
- **붙여넣기 텍스트**가 있으면 `work/input.txt`에 저장하고 그 경로를 사용한다.
- **입력 없음**이면 `make_sample.py --out work --seed 42`를 실행해 합성 샘플 3종을 생성한 뒤 점검한다. 합성 샘플은 (1) 명부 CSV(이름·주민등록번호·휴대전화·이메일·주소·학번, 6행), (2) 회의 메모 md(담당자 유선전화, Luhn 통과 가상 카드번호, 은행명+계좌, 체크섬 통과 가상 사업자등록번호, 사설 IP, 신형 여권번호, 생년월일+이름), (3) 설정 파일 env(OPENAI_API_KEY=sk-…40자, AWS AKIA/ASIA+16자, GITHUB_TOKEN=ghp_…36자, DATABASE_URL=postgres 접속문자열, password).

### 2) scan_pii.py 실행

```
python pii-guard/scripts/scan_pii.py <파일들...> \
  --json work/pii.json \
  --md work/report.md \
  --masked-dir work/masked \
  [--no-names] \
  [--min-confidence info|low|medium|high]
```

- 텍스트 파일은 utf-8-sig→utf-8→cp949→euc-kr→latin-1 순서로 디코딩한다.
- 문서 파일(docx/hwpx/pptx/xlsx)은 zip 안의 XML에서 태그를 제거해 텍스트를 추출한다.
- 5MB 초과·NUL 바이트 포함(바이너리)·손상 zip은 건너뛰고 사유를 기록한다.
- 종료코드: 0=탐지 없음, 1=탐지 있음, 2=입력 오류(파일 없음·5MB 초과 등).

### 3) 결과 보고

- 화면에 **위험도·유형별 탐지표·권고 조치**를 출력한다.
- `work/report.md`(요청 시 `--md`가 가리키는 경로)와 `work/pii.json`을 저장한다.
- `work/masked/`에 마스킹본 파일(`{원본명}.masked.{ext}`, 문서는 `.txt`)을 생성한다.
- **HIGH**면 화면 첫 줄에 "[주의] HIGH 위험: …" 경고를 출력한다.

### 4) 한계 문구

보고서 하단에 "한계: ① 이름·주소 등 문맥 기반 탐지는 키워드 존재 여부에 의존하므로 문맥어가 없는 경우 누락될 수 있습니다. ② 이미지·스캔 PDF는 OCR을 지원하지 않아 텍스트 추출이 불가능합니다. ③ …" 문구를 포함한다.

## 출력 형식

보고서는 다음 5개 부분으로 구성된다.

1. **요약** — 점검 시각, 대상, 위험도, 탐지 건수, 처리 파일 수, 원칙 문구.
2. **유형별 탐지 집계 표** — 유형 / 파일 수 / 건수 / 최고 신뢰도 / 마스킹 예시.
3. **위치별 상세 (상위 40건)** — 파일·줄·유형·신뢰도·검증 여부·마스킹된 문맥. 전체 목록은 JSON 보고서.
4. **권고 조치** — 위험도에 따른 조치(공유 중단, 마스킹본 사용, 원본 처리, 접근 제한 등).
5. **법적 근거(참고)** — 개인정보 보호법 제24조·제24조의2·제29조 관련 문구 + 한계 문구.

## 예외 처리

| 상황 | 처리 |
|------|------|
| 입력 없음 | 사용법 안내 + 합성 샘플 3종 생성·점검 시연(HIGH 예시 포함). |
| 바이너리·이미지·스캔 PDF | "텍스트 추출 불가 — 텍스트/CSV/DOCX로 변환 후 재시도" 안내. |
| 5MB 초과 | "분할해서 검사" 안내. |
| 인코딩 깨짐 | utf-8→cp949→euc-kr→latin-1 순 시도, 마지막은 대체문자. |
| 탐지 0건 | "탐지 없음 — 단, 이름·주소 등 문맥 기반 항목은 누락 가능" 문구. |
| 대량 탐지(수백 건) | 유형별 집계 + 상위 40건만 상세, 전체는 JSON. |
| 오탐 의심(주문번호·좌표·버전) | 검증 실패 → 미보고 또는 low, 사용자 확인 권고. |
| 2020.10 이후 주민번호 | 검증번호 없음 → medium '형식만' + 사유 표기. |
| 문서 파일(docx/hwpx/pptx/xlsx) | zip+XML 텍스트 추출 후 검사, 마스킹본은 .txt. |
| 이름 오탐이 많은 문서 | `--no-names` 재실행. |
| 사용자가 원문 값 출력을 요구 | 정중히 거절(마스킹값·위치만 제공). |
| 스크립트 오류 | 오류 메시지 보고, 임의 결과 금지. |

## 품질 규칙

- 탐지 원문 값은 대화·보고서에 절대 그대로 노출하지 않는다(마스킹값·위치만).
- 위험도 문구와 한계 문구를 생략하지 않는다.
- 스크립트 결과를 임의로 늘리거나 줄이지 않는다.
- 마스킹본은 비가역·유형별 고정으로 생성한다.

## 기존 스킬과의 차이 (관리자 참고)

단순 정규식 기반 grep과 달리, 체크섬 검증(주민번호 검증번호·사업자번호 체크섬·Luhn)·CSV 열 문맥(이름·학번 등)·비밀키 패턴(OpenAI/AWS/GitHub/Google/Slack/JWT/PRIVATE KEY/접속문자열)·비가역 마스킹본 생성·법적 근거 안내를 한 번에 제공한다. 위험도 자동 판정(HIGH/MEDIUM/LOW/NONE)도 포함된다.

## 파일 구성

```
pii-guard/
├─ SKILL.md                         # 이 파일
├─ scripts/
│  ├─ scan_pii.py                   # 탐지·검증·마스킹·보고서(JSON/MD)
│  └─ make_sample.py                # 합성 시연 데이터 생성(고정 시드 42)
└─ references/
   └─ detection_catalog.md          # 유형·검증·마스킹 규칙·위험도·한계
```

## 사용 예시

```
# 첨부 파일 점검
python pii-guard/scripts/scan_pii.py 명부.csv 회의록.md .env \
  --json work/pii.json --md work/report.md --masked-dir work/masked

# 텍스트 붙여넣기
python pii-guard/scripts/scan_pii.py --text "이름: 홍길동, 주민번호: ######-#######, 연락: 010-1234-5678"

# 이름 탐지 제외
python pii-guard/scripts/scan_pii.py 파일.csv --no-names

# 높은 신뢰도만 보고
python pii-guard/scripts/scan_pii.py 파일.txt --min-confidence medium

# 입력 없을 때 합성 샘플 시연
python pii-guard/scripts/make_sample.py --out work --seed 42
python pii-guard/scripts/scan_pii.py work/sample_roster.csv work/sample_notes.md work/sample_config.env \
  --json work/pii.json --md work/report.md --masked-dir work/masked
```

> **주의**: 시연 데이터는 실행 시점에 합성 생성된다. 스킬 폴더 안에는 주민번호·전화·이메일·카드 번호·API 키처럼 보이는 완성된 예시 값이 존재하지 않는다(패턴 설명만 `######-#######` 같은 추상 표기로 기재).
