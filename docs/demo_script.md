**내레이션:**

## 장면 ② 진행률 (10초)

**화면 상태:**
- 파이프라인 로그가 단계별로 스크롤:
  ```
  parse        → 캐시 재사용 (요소 18개)
  separate     → 참고문헌 헤딩 발견, 본문 14개 + ref 1개
  law         → 법령 표지 4건 추출 → ⛔스냅샷미보유 4
  subcontract → 총 18항목, 위험신호 1건
  verify      → 참고문헌 1건 파싱, unverified 1
  extract_claims → 주장 1건 추출
  link_check  → 미인용 1건, 목록 누락 1건
  match       → 대조 완료: 판단 불가 1
  photo       → 사진 섹션: 주장 3건, 매칭성공 2, 매칭실패 1, 뒷받침함 1, 뒷받침안함 1
  gate        → 문서 게이트: 보완 필요
  ```
- 총 소요 시간: **18.68초**

**내레이션:**
> "파싱부터 게이트까지 6개 섹션이 순차적으로 돈다. 법령 표지 4건을 뽑고, 적법도급 체크리스트 18항목을 점검하고, 참고문헌 1건을 검증하고, 사진 3건의 주장을 사진 2장과 대조한다. 전부 19초 안에 끝난다."

## 장면 ④ 클라이맥스: 🔴 오인용 항목 클릭 — 본문 주장 ↔ 초록 원문 대비 (60초)

### 4-1. 사진 카드: "보고서는 '정리 양호', 사진에선 방치 적재물 검출" (30초)

**화면 상태:**
- 사진 섹션에서 `[사진 2]` 항목 확장:
  ```
  문장: [사진 2] A동 1층 하역장은 적재물이 정리되어 양호하다.
  판정: ❌ 뒷받침 안 함
  검출 도메인: cleaning
  검출 객체: cardboard 2건
  quote: cardboard
  사유: "주장 중 사진에 보이는 상태에 대한 서술은 '적재물이 정리되어 양호하다'입니다.
         그러나 검출된 객체 목록에 방치된 적재물·폐기물로 해석 가능한 cardboard가 2건 검출되어,
         서술과 모순됩니다."
  ```
- 옆에 실제 사진(`R1_L2_A동_1층_하역장.jpg`)과 검출 박스 시각화(가능 시)

**내레이션:**
> "여기다. 보고서는 A동 1층 하역장이 '적재물이 정리되어 양호하다'고 썼다. 그런데 같은 위치의 사진을 YOLO cleaning 도메인으로 돌렸더니 cardboard(방치된 골판지)가 2건 검출됐다. 보고서는 정리됐다고 주장하지만, 사진은 그 반대를 말한다. 이게 🔴 뒷받침 안 함 — 오인용이다. 이 한 건 때문에 문서 게이트가 '보완 필요'로 떨어졌다."

### 4-2. 적법도급 카드: "직접 작업 지시" 위험 신호 + 근거 문장 (20초)

**화면 상태:**
- 적법도급 섹션에서 축1 항목1 확장:
  ```
  [축 1·항목 1] 작업 지시·명령의 원청 직접성
  판정: 근거 있음-위험 신호
  근거 문장:
    1. "하역 작업과 관련하여, 원청인 가온물류센터 직원의 직접 작업 지시로 인하여 수급인"
    2. "직원이 수급인 근로자에게 직접 작업 지시를 한 사례로서 적법도급 요건에 위배될 소지가"
  위험 키워드: 직접 작업 지시
  ```

**내레이션:**
> "적법도급 체크리스트도 하나 걸렸다. 원청 직원이 수급인 근로자에게 직접 작업 지시를 한 정황이 본문에 있고, 체크리스트가 이를 근거 문장과 함께 잡아냈다. 이건 사람의 최종 판단이 필요한 위험 신호지만, 최소한 어디에 근거가 있는지 수작업으로 뒤지지 않아도 된다."

### 4-3. 법령 카드: 환각 조항 ❌ (스냅샷 확보 후) (10초)

**화면 상태:**
- 법령 섹션에서 「산업안전보건법」 제999조 항목 확장:
  ```
  ⛔ 스냅샷 미보유
  법령명: 산업안전보건법 / 제999조
  note: "'산업안전보건법'(조 999조)의 스냅샷은 있으나 조문이 비어 있어 조문 본문을 제공할 수 없음"
  ```
- (스냅샷 확보 후에는) "해당 조 없음" 또는 실존 조문의 경우 조문 본문 대비 화면

**내레이션:**
> "보고서에서 '산업안전보건법 제999조'라고 인용했다. 제999조는 실존하지 않는 조문이다 — AI가 만들어낸 환각 조항. 이 서비스는 스냅샷에서 조문을 찾지 못하면 ⛔로 표시한다. 스냅샷이 확보되면 '해당 조 없음'으로 명확히 판정한다. LLM이 조문 본문을 만들지 않는다는 원칙이 여기서 작동한다."
