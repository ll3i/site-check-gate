# verification_rules.md — 참고문헌 검증 규칙 및 한계

## 1. 소스

| 소스 | 용도 | 엔드포인트 예 |
|---|---|---|
| doi.org 핸들 API | DOI 등록 여부 확인 (responseCode 1 = 등록됨) | `https://doi.org/api/handles/{DOI}` |
| Crossref | DOI 서지 메타데이터 (저자·연도·제목·컨테이너·URL) | `https://api.crossref.org/works/{DOI}` |
| DataCite | Crossref에 없는 DOI 서지 대체 | `https://api.datacite.org/dois/{DOI}` |
| arXiv API | arXiv ID 실존 확인 + 서지 (제목·저자·연도·요약·PDF URL) | `http://export.arxiv.org/api/query?id_list={id}` |
| Crossref 검색 | DOI/arXiv가 없을 때 제목·문헌 검색 | `works?query.title=`, `works?query.bibliographic=` |
| arXiv 제목 검색 | 영문·비단행본일 때 제목 기반 검색 | `search_query=ti:"제목"` |

## 2. 판정 기준 (고정 문자열)

| 판정 | 의미 | 조건 |
|---|---|---|
| ✅ 확인 | 앵커(DOI/arXiv id)로 실존 확인 + 제목 유사도 ≥0.85 + 연도차 ≤1 + 제1저자 불일치 없음 | 앵커 기반 |
| ✅ 확인(검색 기반) | 검색에서 실존 확인 + 유사도 ≥0.85 + 저자/연도 조건 충족 | 검색 기반, 짧은 제목(2단어 이하)은 저자 일치 필요 |
| ⚠️ 부분일치 | 실존하지만 연도차 ≥2, 제1저자 다름, 제목 유사도 기준 미만, DOI 미등록이지만 제목·저자로 실존 확인(→ 교정 DOI 제시), DOI가 다른 문헌을 가리킴, 동명 제목 다수(저자·연도 근접 후보 선택 + 후보 목록) | |
| ❌ 미확인 | 어떤 소스에서도 근거 없음. **가짜 단정 아님** — 비고에 한계 문구 포함 (국문: KCI/RISS/DBpia, 단행본: ISBN, 그 외: 생성 가능성·인용 보류) | |
| ⛔ 확인불가 | 네트워크 오류·타임아웃 → 재실행 안내. 절대 ✅/❌로 바꾸지 않음 | |
| ➖ 비대상 | 웹페이지·소프트웨어 문서 등 DOI 대상 아님 → URL 응답 코드만 | kind=web |

## 3. 유사도 계산

- `difflib.SequenceMatcher.ratio()` 기반, 소문자화 후 구두점 제거.
- 한쪽이 다른 쪽의 접두어면 0.9 보정.
- 검증 스크립트는 유사도를 소수점 4자리에서 반올림하여 2자리로 표시.

## 4. 호출 예절

- User-Agent 명시, 이메일 없음: `cite-check/1.0 (references verification)`
- 요청 간 0.35초 대기
- 타임아웃 12초
- 5xx/429 는 1회 재시도
- 1회 실행 최대 60건 (초과 시 나눠서 재실행 안내)

## 5. 교정 서지 원칙

- ✅/⚠️ 항목의 교정 서지는 **소스 메타데이터를 그대로** 옮김.
- 입력(raw)은 수정하지 않고 보고서에 함께 표시.
- 사람이 임의로 상태 변경 금지 — 판정은 스크립트 결과만 사용.

## 6. 한계

- 국문 학술지는 Crossref 미색인 가능성이 높아 영어 메타데이터만으로는 유사도가 낮게 나올 수 있음.
- 단행본·보고서는 색인이 불완전할 수 있음.
- 자동 검증은 참고용이며 최종 판단은 사람이 수기로 해야 함.
- "❌ 미확인"을 "가짜"라고 단정하지 않음 — 생성 가능성·인용 보류 시사.
- DOI가 등록되었지만 서지 API에서 매칭되지 않으면 ⚠️로 표시 + 오기재 가능성 알림.
- 동명 제목 다수 시 후보 목록으로 표시하고 저자·연도 근접 후보 선택.

## 7. 예외 처리 요약

- 입력 없음 → 사용법 + 내장 샘플 시연
- 참고문헌 아닌 텍스트 → 안내 후 종료 (parse 결과 0건 또는 연도·저자 전무)
- 항목 분리 실패 → --mode paragraphs/lines 재시도, 그래도 이상하면 번호 붙여 달라고 요청
- 60건 초과 → 처음 60건만 검증, 나머지 분할 재실행 안내
- 네트워크 차단·타임아웃 → ⛔ 다수, 상태 그대로 보고, 재실행 안내 (절대 ✅/❌ 변경 금지)
- API 429/5xx → 재시도 후 실패 시 해당 항목 ⛔
- DOI 오타(미등록) → ❌ 또는 제목·저자로 실존 확인 시 ⚠️ + 교정 DOI
- DOI 실존하나 다른 문헌 → ⚠️ + "DOI 오기재 가능성" + 후보
- 국문·단행본·보고서 → ❌ + 수동 확인 경로 힌트 (KCI/RISS/DBpia, ISBN)
- 웹·소프트웨어 문서 → ➖ 비대상 + URL 응답 코드
- 동명 제목 다수 → 저자·연도 근접 후보 선택 + "후보 목록 확인" 비고
- 개인정보 포함 입력 → 참고문헌 외 텍스트는 보고서에 옮기지 않음
- 스크립트 오류 → 오류 메시지 보고, 임의 판정 금지
